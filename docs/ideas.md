## Голос жителей в карточке (отложено 1 октября 2026)

Идея: люди захотят высказаться, а не только нажать «Я тоже вижу».

Риск: свободные комментарии спорят с принципом «только факты, без оценок и обвинений», за опубликованное отвечает владелец сайта, а каждый комментарий придётся проверять до публикации.

Предложенный порядок:

1. Показывать в карточке комментарий автора отметки. Он уже собирается и проходит модерацию вместе с фото; модератору нужна возможность опубликовать отметку без комментария.
2. Подтверждающим дать готовые причины вместо текста: «не проехать на машине», «не пройти с коляской», «скользко», «сосульки над входом», «кучи не вывозят». В карточке — счётчики по причинам. Модерация не нужна. Формулировки стоит взять из реальных жалоб клиентов ДА МОГУ.
3. Свободные комментарии подтверждающих (до 200 знаков, только после одобрения) — вместе с Telegram-ботом, где у модератора будут кнопки.

При любом варианте поправить тексты о том, что публикуется.

## Онлайн-карта вместо своего файла (отложено 1 октября 2026)

Сейчас карта — свой файл Томска, обновляется пересборкой. Вариант: основная карта с OpenFreeMap (обновляется сама, весь мир), свой файл — запасной при сбое. Перед этим проверить доступность openfreemap.org из Томска без VPN: сервис работает через Cloudflare.
